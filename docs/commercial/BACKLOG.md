# 90-day backlog

Week 1 starts 2026-10-23. Each week has one commercial action and one product action. Revenue cells stay at zero until a payment is recorded.

| Week starting | Commercial action | Product action |
| --- | --- | --- |
| 2026-10-23 | Review the PR, choose whether to approve the license draft, and pick one Upwork niche search phrase. Send nothing yet. | Land the formatted workbook, CI, and ZIP. |
| 2026-10-30 | Write the US$99 project offer in Upwork drafts. Submit only after a specific buyer is approved. | Fix any CI failure from the first PR. |
| 2026-11-06 | Ask three bookkeeping contacts the discovery questions. Record replies as leads only when they name a file and a deadline. | Add a column-mapping example if a real file needs it. |
| 2026-11-13 | Publish the Gumroad draft only if the license is approved. | Build the ZIP from the merged commit and install it in a clean directory. |
| 2026-11-20 | Send the first approved proposal. Log it on the Actuals sheet. | Adjust the rejection reasons to match that buyer's columns. |
| 2026-11-27 | Follow up once on unanswered proposals. | No new feature unless a buyer asks. |
| 2026-12-04 | Deliver the first paid file if one exists. | Record counts in the delivery note. |
| 2026-12-11 | Ask that buyer whether they want the same run next month. | Turn the repeated steps into the Advanced runbook only if they pay for it. |
| 2026-12-18 | Decide whether a second proposal is justified by a reply. | Leave SaaS unbuilt if nobody has paid. |
| 2026-12-25 | Close the year with actual cash only. | Tag a version only after the license decision. |
| 2027-01-01 | Review response rate from the Actuals formula. | Drop a package that received no reply. |
| 2027-01-08 | Offer Standard only to a buyer who asks for a second file. | Keep one command as the demo. |
| 2027-01-15 | If one buyer asks for a shared login, write the security tests before any host is purchased. | Otherwise keep the local toolkit. |

## Gate

No merge to `master` is automatic. No hosting purchase, paid API, proposal, or listing goes out without an explicit approval.
